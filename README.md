# PowerBI_Sales_Dashboard
An interactive Sales Dashboard created using details.csv and order.csv visualizes key metrics like profit, quantity, and amount across categories, customers, and months. This dashboard enables quick business insights through intuitive charts and KPIs.


# 📊 Sales Dashboard Project

Welcome to the **Sales Dashboard** — a visually compelling analytics tool designed to provide quick and clear insights into business performance using real-time sales data.

## 🚀 Features
- ✅ **Interactive filters** for quarterly analysis  
- 📈 **Dynamic charts** showing profit trends by sub-category, customer, and month  
- 💰 **KPI indicators** for total Quantity, Profit, and Sales Amount  
- 🛍️ Breakdown of **sales by payment mode** and **product category**  
- 🎯 Actionable insights for business decision-making  

## 📂 Data Sources
- `details.csv`: Contains transaction-level details  
- `order.csv`: Includes order information like customer and product details  

## 🛠️ Tech Stack
- **Power BI / Python (as used)**  
- Clean and colorful UI design with gradient themes for better readability  

## 📌 Objective
To empower stakeholders with quick access to sales performance metrics and identify areas of strength and improvement across different business dimensions.
